Ciągi Liczbowe (PP & PR)

Kompletny zbiór wszystkich 48 zadań i podpunktów z arkusza 6. Ciągi.pdf. Zawiera pełne, krok po kroku wyprowadzone rozwiązania, definicje, wzory na sumy, własności ciągów arytmetycznych i geometrycznych, procent składany oraz granice i szeregi geometryczne.

📌 Ciąg Arytmetyczny

Wzór ogólny: $a_n = a_1 + (n-1)r$.

Warunek sąsiedztwa: $a_n = \frac{a_{n-1} + a_{n+1}}{2}$.

Suma $n$ wyrazów: $S_n = \frac{a_1 + a_n}{2} \cdot n = \frac{2a_1 + (n-1)r}{2} \cdot n$.

📌 Ciąg Geometryczny

Wzór ogólny: $a_n = a_1 \cdot q^{n-1}$.

Warunek sąsiedztwa: $a_n^2 = a_{n-1} \cdot a_{n+1}$.

Suma $n$ wyrazów ($q \ne 1$): $S_n = a_1 \cdot \frac{1 - q^n}{1 - q}$.

📌 Szereg Geometryczny (R)

Nieskończona suma jest zbieżna $\iff |q| < 1$.

Suma szeregu: $S = \sum_{n=1}^\infty a_n = \frac{a_1}{1 - q}$.

Kapitalizacja odsetek: $K_n = K_0 \left(1 + \frac{p}{100m}\right)^{m \cdot n}$.

🔍 Zobacz pełne rozwiązanie krok po kroku
Zadanie 4.
Zauważmy, że ostatni składnik to $n^3 = n \cdot n^2$. Wyłączamy $n^2$ przed nawias z lewej strony:
$L = n^2(1 + 2 + 3 + 4 + \dots + n)$.
Suma w nawiasie to suma pierwszych $n$ wyrazów ciągu arytmetycznego o $a_1 = 1, r = 1$: $\frac{1+n}{2} \cdot n = \frac{n(n+1)}{2}$.
Wstawiając: $L = n^2 \cdot \frac{n(n+1)}{2} = \frac{n^3(n+1)}{2} = P$, co kończy dowód (c.k.d.).
Zadanie 5.
Wyznaczamy sumę $a_n + a_{n+1}$:
$a_{n+1} = 2(n+1)^2 + 2(n+1) = 2(n^2 + 2n + 1) + 2n + 2 = 2n^2 + 4n + 2 + 2n + 2 = 2n^2 + 6n + 4$.
$a_n + a_{n+1} = (2n^2 + 2n) + (2n^2 + 6n + 4) = 4n^2 + 8n + 4 = 4(n^2 + 2n + 1) = 4(n+1)^2 = [2(n+1)]^2$.
Ponieważ $n \in \mathbb{N}_+$, liczba $k = 2(n+1) = 2n + 2$ jest liczbą naturalną, zatem $a_n + a_{n+1} = k^2$, c.k.d.
Zadanie 6.
a) Badamy iloraz $\frac{a_{n+1}}{a_n} = \frac{3 \cdot 2^{n+1}}{3 \cdot 2^n} = \frac{2^{n+1}}{2^n} = 2 = \text{const}$. Iloraz jest stały, więc ciąg $(a_n)$ jest geometryczny o $q = 2$.
b) $b_n = (3 \cdot 2^n)^2 = 9 \cdot 4^n$. Iloraz $\frac{b_{n+1}}{b_n} = \frac{9 \cdot 4^{n+1}}{9 \cdot 4^n} = 4 = \text{const}$. Ciąg $(b_n)$ jest geometryczny o ilorazie $q = 4$.
Zadanie 7.
Sprawdzamy warunek ciągu geometrycznego: $b^2 = 4^2 = 16$.
Iloczyn skrajnych wyrazów: $a \cdot c = 2\sqrt{2} \cdot 4\sqrt{2} = 8 \cdot 2 = 16$.
Zachodzi $b^2 = a \cdot c$, więc liczby tworzą ciąg geometryczny. Odpowiedź: B, 3.
Zadanie 7. A)
a) Z wykresu dla punktów $(1, 5)$ i $(2, 3)$: $a_1 = 5$, różnica $r = a_2 - a_1 = 3 - 5 = -2$.
b) $a_n = a_1 + (n-1)r = 5 + (n-1)(-2) = 5 - 2n + 2 = -2n + 7$.
c) Przyrównujemy: $-2n + 7 = -\frac{1}{2}n^2 \iff -4n + 14 = -n^2 \iff n^2 - 4n + 14 = 0$.
Wyróżnik: $\Delta = (-4)^2 - 4(1)(14) = 16 - 56 = -40 < 0$.
Równanie nie ma rozwiązań w $\mathbb{R}$, a więc nie istnieje takie $n \in \mathbb{N}_+$, dla którego $a_n = b_n$.
4: Wykazano: $L = n^2 \cdot \frac{n(n+1)}{2} = \frac{n^3(n+1)}{2} = P$.
5: Wykazano: $a_n + a_{n+1} = [2(n+1)]^2$.
6: a) Tak, $q = 2$; b) Tak, $q = 4$.
7: B, 3 (geometryczny, $b^2 = a \cdot c$).
7.A: a) $a_1 = 5, r = -2$; b) $a_n = -2n + 7$; c) brak takich $n$ ($\Delta = -40 < 0$).
