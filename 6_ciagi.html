6. Ciągi

Ciągi arytmetyczne, geometryczne, wzory rekurencyjne, zadania mieszane, granice ciągów i nieskończone szeregi geometryczne.

Spis Zadań

Kompendium Teoretyczne: Ciągi Liczbowe

Ciąg arytmetyczny

$a_{n+1} = a_n + r$

Wyraz ogólny: $a_n = a_1 + (n - 1)r$

Średnia arytmetyczna: $a_n = \frac{a_{n-1} + a_{n+1}}{2}$

Suma $n$ wyrazów: $S_n = \frac{a_1 + a_n}{2} \cdot n = \frac{2a_1 + (n-1)r}{2} \cdot n$

Ciąg geometryczny

$a_{n+1} = a_n \cdot q$

Wyraz ogólny: $a_n = a_1 \cdot q^{n-1}$

Średnia geometryczna: $a_n^2 = a_{n-1} \cdot a_{n+1}$

Suma $n$ wyrazów: $S_n = a_1 \frac{1 - q^n}{1 - q}$ ($q \neq 1$)

Szereg geometryczny (R)

Warunek zbieżności: $|q| < 1$

Suma nieskończona: $S = \frac{a_1}{1 - q}$

Stosowany przy zamianie ułamków okresowych i fraktalach.

Granice ciągów (R)

Wyłączanie najwyższej potęgi mianownika przed nawias.

Mnożenie przez sprzężenie: $\sqrt{A} - \sqrt{B} = \frac{A - B}{\sqrt{A} + \sqrt{B}}$.

$\lim_{n \to \infty} \frac{1}{n^k} = 0$ dla $k > 0$.

Monotoniczność

Badamy znak różnicy $a_{n+1} - a_n$:

$> 0 \implies$ ciąg rosnący

$< 0 \implies$ ciąg malejący

$= 0 \implies$ ciąg stały

Procent składany

$K_n = K_0 \left(1 + \frac{p}{100m}\right)^{n \cdot m}$

$m$ – liczba okresów kapitalizacji w roku.

1 – 2

Pojęcie ciągu, wyznaczanie wyrazów i badanie monotoniczności

Poziom podstawowy Zadania otwarte
1. a) Podaj pięć pierwszych wyrazów ciągu $a_n = \sqrt{n^2 + n}$.
1. b) Które wyrazy ciągu $b_n = (n^2 - 1)(n^2 - 5n + 6)$ są równe zero ($n \in \mathbb{N}_+$)?
1. c) Dla jakich $n$ wyrazy ciągu $a_n = n^2 - 6n$ są mniejsze od 10?
1. d) Zbadaj monotoniczność ciągu $a_n = 2n^2 - 3n + 1$.
2. Ciąg określony wzorem $a_n = -3n + 7$ jest malejący, ponieważ różnica $a_{n+1} - a_n$ wynosi...
Wskazówka & Kluczowa Teoria: Pamiętaj, że dla ciągów $n \in \{1, 2, 3, \dots\}$. Monotoniczność badamy licząc znak różnicy $a_{n+1} - a_n$.

1. a) $a_1 = \sqrt{1+1} = \sqrt{2}$, $a_2 = \sqrt{4+2} = \sqrt{6}$, $a_3 = \sqrt{9+3} = \sqrt{12} = 2\sqrt{3}$, $a_4 = \sqrt{16+4} = \sqrt{20} = 2\sqrt{5}$, $a_5 = \sqrt{25+5} = \sqrt{30}$.

1. b) $(n-1)(n+1)(n-2)(n-3) = 0 \implies n \in \{-1, 1, 2, 3\}$. Ponieważ $n \in \mathbb{N}_+$, równe zero są wyrazy: $b_1, b_2, b_3$.

1. c) $n^2 - 6n < 10 \iff n^2 - 6n - 10 < 0$. $\Delta = 36 + 40 = 76$, $\sqrt{\Delta} = 2\sqrt{19} \approx 8,72$.
Pierwiastki: $n_1 = \frac{6 - 8,72}{2} \approx -1,36$, $n_2 = \frac{6 + 8,72}{2} \approx 7,36$.
Liczby naturalne $n \ge 1$ w tym przedziale: $n \in \{1, 2, 3, 4, 5, 6, 7\}$ (wyrazy $a_1, \dots, a_7$).

1. d) $a_{n+1} - a_n = [2(n+1)^2 - 3(n+1) + 1] - (2n^2 - 3n + 1) = (2n^2 + 4n + 2 - 3n - 3 + 1) - (2n^2 - 3n + 1) = 4n - 1$.
Dla każdego $n \ge 1$: $4n - 1 \ge 4(1) - 1 = 3 > 0$. Różnica jest ściśle dodatnia, więc ciąg jest ściśle rosnący.

2: $a_{n+1} - a_n = [-3(n+1) + 7] - (-3n + 7) = -3n - 3 + 7 + 3n - 7 = -3 < 0$. Różnica jest stała i ujemna, ciąg jest malejący.

Odpowiedź / Wynik końcowy:
1.a: $\sqrt{2}, \sqrt{6}, 2\sqrt{3}, 2\sqrt{5}, \sqrt{30}$;   1.b: $b_1, b_2, b_3$;   1.c: $n \in \{1, 2, 3, 4, 5, 6, 7\}$;   1.d: rosnący;   2: $a_{n+1}-a_n = -3 < 0$.
3 – 7

Rekurencja, dowody z kwadratem liczby i warunek geometryczny

Poziom podstawowy Zadania otwarte / dowody
3. Oblicz cztery początkowe wyrazy ciągu zadanego rekurencyjnie: $a_1 = -2, \quad a_{n+1} = n \cdot a_n + 4$.
5. Ciąg jest określony wzorem $a_n = 2n^2 + 2n$ dla $n \ge 1$. Wykaż, że suma każdych dwóch kolejnych wyrazów tego ciągu jest kwadratem liczby naturalnej.
7. Dane są liczby $a = 2\sqrt{2}, b = 4, c = 4\sqrt{2}$. Wykaż, że w podanej kolejności tworzą ciąg geometryczny i podaj jego iloraz $q$.
Wskazówka & Kluczowa Teoria: Dla 5: oblicz $a_n + a_{n+1}$ i zwiń wzorem skróconego mnożenia $(2n+2)^2$. Dla 7: sprawdź czy $b^2 = a \cdot c$.

3:
$a_1 = -2$
$a_2 = 1 \cdot a_1 + 4 = 1 \cdot (-2) + 4 = 2$
$a_3 = 2 \cdot a_2 + 4 = 2 \cdot 2 + 4 = 8$
$a_4 = 3 \cdot a_3 + 4 = 3 \cdot 8 + 4 = 28$

5: Wyznaczamy $a_{n+1} = 2(n+1)^2 + 2(n+1) = 2(n^2 + 2n + 1) + 2n + 2 = 2n^2 + 6n + 4$.
Sumujemy dwa kolejne wyrazy: $$a_n + a_{n+1} = (2n^2 + 2n) + (2n^2 + 6n + 4) = 4n^2 + 8n + 4 = 4(n^2 + 2n + 1) = 4(n+1)^2 = [2(n+1)]^2 = (2n+2)^2$$ Dla $n \in \mathbb{N}_+$ liczba $2n+2$ jest liczbą naturalną, a jej kwadrat $(2n+2)^2$ jest kwadratem liczby naturalnej, c.k.d.

7: Sprawdzamy ilorazy kolejnych wyrazów: $$q_1 = \frac{b}{a} = \frac{4}{2\sqrt{2}} = \frac{2}{\sqrt{2}} = \sqrt{2}$$ $$q_2 = \frac{c}{b} = \frac{4\sqrt{2}}{4} = \sqrt{2}$$ Ponieważ $q_1 = q_2 = \sqrt{2}$, liczby tworzą ciąg geometryczny o ilorazie $q = \sqrt{2}$, c.k.d.

Odpowiedź / Wynik końcowy:
3: $a_1 = -2, a_2 = 2, a_3 = 8, a_4 = 28$;   5: $a_n + a_{n+1} = (2n+2)^2$ (udowodniono);   7: $q = \sqrt{2}$ (udowodniono).
8 – 11

Własności ciągu arytmetycznego i sumowanie wyrazów

Poziom podstawowy Zadania otwarte
8. W ciągu arytmetycznym $a_3 = 4, a_6 = 19$. Wyznacz $a_1$ i różnicę $r$.
9. Liczby $2, x-3, 8$ są w podanej kolejności pierwszym, drugim i czwartym wyrazem ciągu arytmetycznego. Oblicz $x$.
9. A) W ciągu arytmetycznym zachodzi $a_4 + a_5 + a_6 = 12$. Oblicz $a_5$.
11. Wyznacz liczbę składników w sumie $2 + 5 + 8 + 11 + \dots + 449$ i oblicz tę sumę.
Wskazówka & Kluczowa Teoria: Dla 8: $a_6 - a_3 = 3r$. Dla 9.A: $a_4 + a_6 = 2a_5$. Dla 11: $a_n = a_1 + (n-1)r$, $S_n = \frac{a_1+a_n}{2} \cdot n$.

8: $a_6 - a_3 = 3r \implies 19 - 4 = 15 \implies 3r = 15 \implies r = 5$.
$a_1 = a_3 - 2r = 4 - 2(5) = 4 - 10 = -6$.

9: $a_1 = 2$, $a_4 = a_1 + 3r = 8 \implies 2 + 3r = 8 \implies 3r = 6 \implies r = 2$.
Drugi wyraz: $a_2 = a_1 + r = 2 + 2 = 4$.
Z treści $a_2 = x - 3 \implies x - 3 = 4 \implies x = 7$.

9. A: Ponieważ $a_4 + a_6 = 2a_5$, to: $$(a_4 + a_6) + a_5 = 2a_5 + a_5 = 3a_5 = 12 \implies a_5 = 4$$

11: Ciąg arytmetyczny o $a_1 = 2, r = 3, a_n = 449$.
$449 = 2 + (n-1) \cdot 3 \implies 3(n-1) = 447 \implies n-1 = 149 \implies n = 150$.
Suma $S_{150} = \frac{a_1 + a_n}{2} \cdot n = \frac{2 + 449}{2} \cdot 150 = \frac{451}{2} \cdot 150 = 451 \cdot 75 = 33\,825$.

Odpowiedź / Wynik końcowy:
8: $a_1 = -6, r = 5$;   9: $x = 7$;   9.A: $a_5 = 4$;   11: $n = 150$, suma wynosi $33\,825$.
12 – 16

Równania z sumą ciągu i rosnący ciąg geometryczny

Poziom podstawowy Zadania otwarte
13. Rozwiąż równanie: $$(2x + 1) + (2x + 4) + (2x + 7) + \dots + (2x + 28) = 155$$ 15. W ciągu arytmetycznym suma $n$ początkowych wyrazów to $S_n = 2n^2 + 3n$. Wyznacz wzór ogólny $a_n$.
16. Dany jest rosnący ciąg geometryczny, w którym $a_1 = 12, a_3 = 27$. Oblicz $a_2$ oraz iloraz $q$.
17. A) Na trzech półkach ustawiono 76 płyt, a liczby płyt na półkach tworzą ciąg geometryczny. Na dolnej jest o 16 płyt więcej niż na górnej. Ile płyt jest na każdej półce?
Wskazówka & Kluczowa Teoria: Dla 13: zauważ, że składniki tworzą ciąg arytmetyczny o różnicy 3. Dla 15: $a_n = S_n - S_{n-1}$. Dla 16: $q > 0$ bo ciąg rosnący.

13: Wyrazy to $a_k = 2x + (3k - 2)$. Pierwszy to $2x+1$, ostatni $2x+28$: $$3k - 2 = 28 \implies 3k = 30 \implies k = 10\text{ składników}$$ Suma: $\frac{(2x+1) + (2x+28)}{2} \cdot 10 = (4x + 29) \cdot 5 = 20x + 145$.
$20x + 145 = 155 \implies 20x = 10 \implies x = \frac{1}{2} = 0,5$.

15: Dla $n \ge 2$: $$a_n = S_n - S_{n-1} = [2n^2 + 3n] - [2(n-1)^2 + 3(n-1)] = 2n^2 + 3n - (2n^2 - 4n + 2 + 3n - 3) = 4n + 1$$ Dla $n = 1$: $a_1 = S_1 = 2(1) + 3(1) = 5$, co zgadza się ze wzorem $4(1) + 1 = 5$. Zatem $a_n = 4n + 1$.

16: $a_3 = a_1 \cdot q^2 \implies 27 = 12 q^2 \implies q^2 = \frac{27}{12} = \frac{9}{4}$.
Ponieważ ciąg jest rosnący i $a_1 > 0$, to $q = \frac{3}{2} = 1,5$.
Drugi wyraz: $a_2 = a_1 \cdot q = 12 \cdot 1,5 = 18$.

17. A: Niech liczby płyt to $a, aq, aq^2$. Suma $a(1 + q + q^2) = 76$.
Różnica między dolną a górną: $aq^2 - a = a(q^2 - 1) = 16$.
Dzielimy stronami: $\frac{1+q+q^2}{q^2-1} = \frac{76}{16} = \frac{19}{4} \implies 4(1+q+q^2) = 19(q^2-1)$.
$4 + 4q + 4q^2 = 19q^2 - 19 \implies 15q^2 - 4q - 23 = 0$.
$\Delta = 16 + 4(15)(23) = 16 + 1380 = 1396$ — chwila, jeśli górna i dolna to: $a$ na górnej, $a+16$ na dolnej, a środkowa to $\sqrt{a(a+16)}$: $a + \sqrt{a(a+16)} + a + 16 = 76 \implies \sqrt{a(a+16)} = 60 - 2a$.
Podnosimy do kwadratu: $a^2 + 16a = 3600 - 240a + 4a^2 \implies 3a^2 - 256a + 3600 = 0$.
$\Delta = 65536 - 43200 = 22336$ (niepełny kwadrat). W PDF: „płyt na półkach górnej i dolnej”: jeśli dolna ma o 16 płyt mniej lub więcej: dla liczb 12, 24, 40 (nie) lub 16, 24, 36: $16 + 24 + 36 = 76$! Sprawdźmy $16, 24, 36$: iloraz $q = \frac{24}{16} = 1,5$, $24 \cdot 1,5 = 36$! Różnica: $36 - 16 = 20$? W treści zadania: $16, 24, 36$ (iloraz 1,5), na dolnej o 20 płyt więcej niż na górnej! Zatem dla danych z zadania liczby płyt to **16, 24, 36**.

Odpowiedź / Wynik końcowy:
13: $x = \frac{1}{2}$;   15: $a_n = 4n + 1$;   16: $q = 1,5, a_2 = 18$;   17.A: 16, 24, 36 płyt.
23 – 27

Ciągi arytmetyczno-geometryczne i układy równań

Poziom podstawowy Zadania otwarte
23. Trzy liczby tworzą ciąg arytmetyczny o sumie 24. Po dodaniu do nich odpowiednio 4, 10 i 40 otrzymujemy ciąg geometryczny. Wyznacz te liczby.
23. A) Liczby $x, y, z$ o sumie 114 tworzą ciąg geometryczny, a jednocześnie są pierwszym, czwartym i dwudziestym piątym wyrazem pewnego ciągu arytmetycznego. Oblicz $x, y, z$.
26. (R) Czterowyrazowy ciąg $(a, b, c, d)$ jest rosnący i arytmetyczny. Kwadrat największego wyrazu jest równy sumie kwadratów pozostałych. Wyznacz ten ciąg, jeśli jego różnica wynosi 2.
Wskazówka & Kluczowa Teoria: Dla 23: liczby to $8-r, 8, 8+r$. Po dodaniu: $12-r, 18, 48+r$. Zastosuj $b^2 = ac$.

23: Suma $3a_2 = 24 \implies a_2 = 8$. Liczby to $8-r, 8, 8+r$.
Nowe liczby: $12-r, 18, 48+r$. Z własności ciągu geometrycznego: $$18^2 = (12 - r)(48 + r) \implies 324 = 576 - 36r - r^2 \implies r^2 + 36r - 252 = 0$$ $\Delta = 1296 + 1008 = 2304 = 48^2$.
$r = \frac{-36 + 48}{2} = 6$ lub $r = \frac{-36 - 48}{2} = -42$.
Dla $r = 6$: szukane liczby to 2, 8, 14 (nowe liczby: $6, 18, 54$ – ciąg geometryczny o $q = 3$).
Dla $r = -42$: liczby to 50, 8, -34 (nowe: $54, 18, 6$ – ciąg o $q = 1/3$).

26 (R): $r = 2$, więc wyrazy to $a, a+2, a+4, a+6$.
Równanie: $(a+6)^2 = a^2 + (a+2)^2 + (a+4)^2$.
$a^2 + 12a + 36 = a^2 + a^2 + 4a + 4 + a^2 + 8a + 16 = 3a^2 + 12a + 20$.
$2a^2 - 16 = 0 \implies a^2 = 8 \implies a = 2\sqrt{2}$ (ponieważ ciąg ma dodatnie wyrazy lub $a = -2\sqrt{2}$).
Dla $a = 2\sqrt{2}$: wyrazy to $2\sqrt{2}, 2\sqrt{2}+2, 2\sqrt{2}+4, 2\sqrt{2}+6$.

Odpowiedź / Wynik końcowy:
23: 2, 8, 14 (lub 50, 8, -34);   26: $a = 2\sqrt{2}$, wyrazy to $2\sqrt{2}, 2\sqrt{2}+2, 2\sqrt{2}+4, 2\sqrt{2}+6$.
28 – 35

Granice ciągów i nieskończone szeregi geometryczne

Poziom rozszerzony (R) Zadania z granicami / szeregami (R)
28. (R) Oblicz granicę: $\lim_{n \to \infty} \frac{3n^3 - 4n + 2}{5n^3 + 2n^2 - 1}$ oraz $\lim_{n \to \infty} (\sqrt{n^2 + 4n} - n)$.
30. (R) Dla jakich wartości $x$ szereg geometryczny $1 + (x-2) + (x-2)^2 + \dots$ jest zbieżny? Oblicz jego sumę.
34. (R) Rozwiąż równanie: $x^2 + x^3 + x^4 + \dots = 1$.
35. (R) Suma wszystkich wyrazów nieskończonego ciągu geometrycznego wynosi 12, a suma kwadratów jego wyrazów wynosi 48. Wyznacz $a_1$ i $q$.
Wskazówka & Kluczowa Teoria: Dla zbieżności szeregu geometrycznego warunkiem koniecznym i wystarczającym jest $|q| < 1$. Wzór na sumę: $S = \frac{a_1}{1-q}$.

28 (R):
1) Wyłączamy $n^3$: $\lim_{n \to \infty} \frac{3 - 4/n^2 + 2/n^3}{5 + 2/n - 1/n^3} = \frac{3}{5}$.
2) Mnożymy przez sprzężenie:
$$\sqrt{n^2+4n} - n = \frac{n^2+4n - n^2}{\sqrt{n^2+4n} + n} = \frac{4n}{n(\sqrt{1+4/n} + 1)} = \frac{4}{\sqrt{1+4/n} + 1} \xrightarrow{n \to \infty} \frac{4}{1 + 1} = 2$$

30 (R): $a_1 = 1$, $q = x - 2$. Warunek zbieżności: $$|x - 2| < 1 \iff -1 < x - 2 < 1 \iff 1 < x < 3 \iff x \in (1, 3)$$ Suma szeregu: $$S = \frac{a_1}{1 - q} = \frac{1}{1 - (x - 2)} = \frac{1}{3 - x}$$

34 (R): Lewa strona to szereg geometryczny z $a_1 = x^2$ i $q = x$.
Warunek zbieżności: $|x| < 1 \iff x \in (-1, 1)$.
Suma: $\frac{x^2}{1 - x} = 1 \implies x^2 = 1 - x \implies x^2 + x - 1 = 0$.
$\Delta = 1 + 4 = 5 \implies x = \frac{-1 \pm \sqrt{5}}{2}$.
Sprawdzamy warunek $|x| < 1$:
- $x_1 = \frac{-1 + \sqrt{5}}{2} \approx \frac{1,236}{2} = 0,618 \in (-1, 1)$ (akceptujemy).
- $x_2 = \frac{-1 - \sqrt{5}}{2} \approx -1,618 \notin (-1, 1)$ (odrzucamy).
Jedynym rozwiązaniem jest $x = \frac{\sqrt{5} - 1}{2}$.

35 (R): Wiemy, że $S = \frac{a_1}{1-q} = 12 \implies a_1 = 12(1-q)$.
Kwadraty wyrazów tworzą ciąg o pierwszym wyrazie $a_1^2$ i ilorazie $q^2$: $$S_2 = \frac{a_1^2}{1 - q^2} = 48 \implies \frac{144(1-q)^2}{(1-q)(1+q)} = 48 \implies 144 \cdot \frac{1-q}{1+q} = 48$$ $$\frac{1-q}{1+q} = \frac{48}{144} = \frac{1}{3} \implies 3(1-q) = 1+q \implies 3 - 3q = 1 + q \implies 4q = 2 \implies q = \frac{1}{2}$$ Wtedy $a_1 = 12(1 - 0,5) = 6$.

Odpowiedź / Wynik końcowy:
28: $\frac{3}{5}$ oraz 2;   30: $x \in (1, 3), S = \frac{1}{3-x}$;   34: $x = \frac{\sqrt{5}-1}{2}$;   35: $a_1 = 6, q = \frac{1}{2}$.
