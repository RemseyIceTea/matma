Wielomiany (PP & PR)

Kompletny zbiór wszystkich zadań i podpunktów z arkusza 7. Wielomiany.pdf. Zawiera pełne rozwiązania, twierdzenie Bézouta, schemat Hornera, dzielenie pisemne z resztą, pierwiastki całkowite i wymierne, wężyk wielomianowy oraz zadania z parametrem i rachunkiem różniczkowym.

📌 Twierdzenie Bézouta

Liczba $a$ jest pierwiastkiem wielomianu $W(x) \iff W(a) = 0 \iff W(x)$ dzieli się bez reszty przez $(x - a)$.

Reszta z dzielenia $W(x)$ przez $(x - a)$ jest zawsze równa $R = W(a)$.

📌 Dzielenie Wielomianów

$W(x) = P(x) \cdot Q(x) + R(x)$, gdzie $\deg(R) < \deg(P)$.

Gdy dzielimy przez trójmian kwadratowy stopnia 2, reszta ma postać liniową: $R(x) = ax + b$.

📌 Wężyk Wielomianowy (PR)

Przy szkicowaniu znaku iloczynu czynników liniowych:

Dla pierwiastka o krotności nieparzystej (1, 3, ...) wykres przebija oś $OX$.

Dla pierwiastka o krotności parzystej (2, 4, ...) wykres odbija się od osi $OX$.

Zadania 1, 2, 2.A, 3: Stopień wielomianu, tożsamość i rozwiązywanie równań metodą grupowania
Podstawa

1. Wielomian $w(x) = (a^2 - 5a - 6)x^3 + 3x^2 - 8x + 6$ jest wielomianem stopnia drugiego. Wyznacz $a$.

2. Liczba $x = 2$ jest pierwiastkiem wielomianu $w(x) = x^3 - 3x^2 + ax - 4$. Oblicz wartość parametru $a$.

2. A) a) Sprawdź, czy wielomian $w(x) = 8x^3 - 27$ jest równy wielomianowi $p(x) = (2x - 3)(4x^2 + 6x + 9)$.
b) Sprawdź, czy liczby $1, 2, 4$ są pierwiastkami wielomianu $w(x) = x^3 - 7x^2 + 14x - 8$.

3. Rozwiąż równanie:
a) $x^3 - 3x^2 - 4x + 12 = 0$,
b) $2x^3 - x^2 - 8x + 4 = 0$,
c) $x^4 - 5x^2 + 4 = 0$,
d) $x^3 - 6x^2 + 12x - 8 = 0$,
e) $3x^3 + 2x^2 - 3x - 2 = 0$.

🔍 Zobacz pełne rozwiązanie krok po kroku
Zadanie 1.
Wielomian jest stopnia 2 wtedy i tylko wtedy, gdy współczynnik przy najwyższej potędze $x^3$ jest równy zero, a współczynnik przy $x^2$ jest różny od zera (tu wynosi $3 \ne 0$).
$a^2 - 5a - 6 = 0 \iff (a - 6)(a + 1) = 0 \iff a = 6 \lor a = -1$.
Zadanie 2.
Skoro $2$ jest pierwiastkiem: $w(2) = 0 \iff 2^3 - 3(2^2) + a(2) - 4 = 0 \iff 8 - 12 + 2a - 4 = 0 \iff 2a - 8 = 0 \iff a = 4$.
Zadanie 2. A)
a) Ze wzoru skróconego mnożenia na różnicę sześcianów: $A^3 - B^3 = (A - B)(A^2 + AB + B^2)$.
Dla $A = 2x, B = 3$: $(2x)^3 - 3^3 = (2x - 3)[(2x)^2 + (2x)(3) + 3^2] = (2x - 3)(4x^2 + 6x + 9)$.
Zatem $p(x) = 8x^3 - 27 = w(x)$. Wielomiany są równe.
b) Obliczamy wartości:
$w(1) = 1 - 7 + 14 - 8 = 0$,
$w(2) = 8 - 28 + 28 - 8 = 0$,
$w(4) = 64 - 7(16) + 14(4) - 8 = 64 - 112 + 56 - 8 = 0$.
Wszystkie trzy liczby $1, 2, 4$ są pierwiastkami wielomianu $w(x)$.
Zadanie 3.
a) Grupujemy: $x^2(x - 3) - 4(x - 3) = 0 \iff (x - 3)(x^2 - 4) = 0 \iff (x - 3)(x - 2)(x + 2) = 0 \implies x \in \{-2, 2, 3\}$.
b) Grupujemy: $x^2(2x - 1) - 4(2x - 1) = 0 \iff (2x - 1)(x^2 - 4) = 0 \implies x \in \{-2, \frac{1}{2}, 2\}$.
c) Równanie dwukwadratowe: podstawiamy $t = x^2 \ge 0$: $t^2 - 5t + 4 = 0 \iff (t - 1)(t - 4) = 0 \implies x^2 = 1 \lor x^2 = 4 \implies x \in \{-2, -1, 1, 2\}$.
d) Wzór na sześcian różnicy: $(x - 2)^3 = 0 \implies x = 2$ (pierwiastek potrójny).
e) Grupujemy: $x^2(3x + 2) - (3x + 2) = 0 \iff (3x + 2)(x^2 - 1) = 0 \implies x \in \{-1, -\frac{2}{3}, 1\}$.
1: $a \in \{-1, 6\}$.
2: $a = 4$.
2.A: a) Tak, są równe; b) Tak, wszystkie trzy liczby są pierwiastkami.
3: a) $x \in \{-2, 2, 3\}$; b) $x \in \{-2, \frac{1}{2}, 2\}$; c) $x \in \{-2, -1, 1, 2\}$; d) $x = 2$; e) $x \in \{-1, -\frac{2}{3}, 1\}$.

🔍 Zobacz pełne rozwiązanie krok po kroku
Zadanie 4.
Układ równań z warunków $w(1) = 0$ i $w(-2) = 0$:
1) $1 - a - 2 + b = 0 \iff -a + b = 1$.
2) $(-2)^3 - a(-2)^2 - 2(-2) + b = 0 \iff -8 - 4a + 4 + b = 0 \iff -4a + b = 4$.
Odejmując: $(-a + b) - (-4a + b) = 1 - 4 \iff 3a = -3 \implies a = -1$.
Wtedy $b = 1 + a = 1 - 1 = 0$. Zatem $a = -1, b = 0$.
Zadanie 5.
a) $w(1) = 2 + a - 14 + b = 0 \iff a + b = 12$.
$w(3) = 2(27) + 9a - 14(3) + b = 54 + 9a - 42 + b = 9a + b + 12 = 0 \iff 9a + b = -12$.
Odejmując stronami: $8a = -24 \implies a = -3$. Wtedy $b = 12 - (-3) = 15$.
b) $w(x) = 2x^3 - 3x^2 - 14x + 15$. Ze wzorów Viète'a iloczyn pierwiastków wynosi: $x_1 \cdot x_2 \cdot x_3 = -\frac{15}{2}$.
$1 \cdot 3 \cdot x_3 = -\frac{15}{2} \implies 3x_3 = -\frac{15}{2} \implies x_3 = -\frac{5}{2} = -2{,}5$.
Zadanie 6.
Dzielniki wyrazu wolnego ($2$): $\{\pm 1, \pm 2\}$.
$w(-1) = (-1)^3 + 2(-1)^2 + 3(-1) + 2 = -1 + 2 - 3 + 2 = 0$. Zatem $x = -1$ jest pierwiastkiem.
Dzielimy przez $x + 1$ (np. Hornerem): iloraz to $x^2 + x + 2$.
Trójmian $x^2 + x + 2 = 0$: $\Delta = 1^2 - 4(1)(2) = 1 - 8 = -7 < 0$ (brak pierwiastków).
Jedynym pierwiastkiem rzeczywistym jest $x = -1$.
Zadanie 7.
Wstawiamy $x = 1$: $2(1)^3 - (3m - 1)(1)^2 + 7(1) - m = 0 \iff 2 - 3m + 1 + 7 - m = 0 \iff 10 - 4m = 0 \iff m = 2{,}5$.
Zadanie 7. A)
a) $w(2) = 0 \iff 2^3 + k(2^2) - 4 = 0 \iff 8 + 4k - 4 = 0 \iff 4k = -4 \implies k = -1$.
b) $w(x) = x^3 - x^2 - 4 = 0$. Dzielimy przez $x - 2$: $(x - 2)(x^2 + x + 2) = 0$.
Ponieważ dla $x^2 + x + 2$ mamy $\Delta = -7 < 0$, jedynym rozwiązaniem jest $x = 2$.
4: $a = -1, b = 0$.
5: a) $a = -3, b = 15$; b) $x_3 = -2{,}5 = -\frac{5}{2}$.
6: $x = -1$.
7: $m = 2{,}5 = \frac{5}{2}$.
7.A: a) $k = -1$; b) $x = 2$.

11. Nie wykonując dzielenia wielomianów, wyznacz resztę z dzielenia wielomianu $w(x) = x^5 - 2x^4 + 3x^3 - 4x^2 + 5x - 6$ przez dwumian $x - 2$.

🔍 Zobacz pełne rozwiązanie krok po kroku
Zadanie 8.
Część wspólna przedziałów $(-\infty; A\rangle$ i $\langle B; \infty)$ jest zbiorem jednoelementowym $\iff A = B$.
$m^3 + 3 = 3m^2 + m \iff m^3 - 3m^2 - m + 3 = 0 \iff m^2(m - 3) - (m - 3) = 0 \iff (m - 3)(m^2 - 1) = 0$.
Rozwiązania to: $m \in \{-1, 1, 3\}$.
Zadanie 9.
Szukamy pierwiastka całkowitego $w(x) = x^3 + 2x^2 - 5x - 6$ spośród dzielników liczby $-6$: $\{\pm 1, \pm 2, \pm 3, \pm 6\}$.
$w(-1) = -1 + 2 + 5 - 6 = 0$. Zatem $a = -1$ (lub sprawdzając inne: $w(2) = 8 + 8 - 10 - 6 = 0 \implies a = 2$, $w(-3) = -27 + 18 + 15 - 6 = 0 \implies a = -3$).
- Dla $a = -1$: $b = -1(-2) = 2$, $c = 2(-2) = -4$. Liczby: $(-1, 2, -4)$.
- Dla $a = 2$: $b = -4, c = 8$. Liczby: $(2, -4, 8)$.
- Dla $a = -3$: $b = 6, c = -12$. Liczby: $(-3, 6, -12)$.
Zadanie 10.
Z twierdzenia Bézouta $w(x)$ jest podzielny przez $x - 1 \iff w(1) = 0$.
$a^2(1)^3 - 4a(1) + 5 = 0 \iff a^2 - 4a + 5 = 0$.
Wyróżnik: $\Delta = (-4)^2 - 4(1)(5) = 16 - 20 = -4 < 0$. Brak rozwiązań rzeczywistych. Nie istnieje taka wartość parametru $a$.
Zadanie 10. A)
Kandydaci na pierwiastki wymierne $\frac{p}{q}$ to dzielniki $21$ przez dzielniki $2$: $p \in \{\pm 1, \pm 3, \pm 7, \pm 21\}$, $q \in \{1, 2\}$.
Sprawdzamy $x = \frac{1}{2}$: $w(1/2) = 2(1/8) - 9(1/4) - 38(1/2) + 21 = \frac{1}{4} - \frac{9}{4} - 19 + 21 = -2 + 2 = 0$.
Dzielimy przez $2x - 1$: iloraz to $x^2 - 4x - 21 = (x - 7)(x + 3) = 0$.
Wszystkie pierwiastki wymierne to: $x \in \{-3, \frac{1}{2}, 7\}$.
Zadanie 11.
Z twierdzenia o reszcie: reszta $R$ z dzielenia wielomianu $w(x)$ przez $x - a$ jest równa wartości wielomianu $w(a)$.
Dla $a = 2$: $R = w(2) = 2^5 - 2(2^4) + 3(2^3) - 4(2^2) + 5(2) - 6 = 32 - 32 + 24 - 16 + 10 - 6 = 12$.
8: $m \in \{-1, 1, 3\}$.
9: $(-1, 2, -4)$ lub $(2, -4, 8)$ lub $(-3, 6, -12)$.
10: $a \in \emptyset$ (brak takich wartości $a$).
10.A: $x \in \{-3, \frac{1}{2}, 7\}$.
11: Reszta $R = 12$.

🔍 Zobacz pełne rozwiązanie krok po kroku
Zadanie 12.
Z podstawowego twierdzenia o dzieleniu wielomianów z resztą: $w(x) = p(x) \cdot q(x) + r(x)$.
Przekształcamy równanie, aby wyznaczyć $p(x)$:
$p(x) \cdot q(x) = w(x) - r(x) = (2x^3 - 5x^2 + x + 1) - (-1) = 2x^3 - 5x^2 + x + 2$.
Dzielimy wielomian $2x^3 - 5x^2 + x + 2$ przez $q(x) = x^2 - 3x + 2$:
- $2x^3 : x^2 = 2x$,
- Odejmujemy $2x(x^2 - 3x + 2) = 2x^3 - 6x^2 + 4x$, zostaje: $(-5x^2 - (-6x^2)) + (x - 4x) + 2 = x^2 - 3x + 2$,
- $(x^2 - 3x + 2) : (x^2 - 3x + 2) = 1$, reszta $0$.
Otrzymujemy wielomian: $p(x) = 2x + 1$.
Zadanie 12. A)
Z treści zadania mamy układ dwóch równań z dwiema niewiadomymi $a, b$:
1) $w(2) = 7 \implies 2^3 + a(2^2) + b(2) + 1 = 7 \iff 8 + 4a + 2b + 1 = 7 \iff 4a + 2b = -2 \iff 2a + b = -1$.
2) Reszta z dzielenia przez $x - 3$ to $w(3) = 10 \implies 3^3 + a(3^2) + b(3) + 1 = 10 \iff 27 + 9a + 3b + 1 = 10 \iff 9a + 3b = -18 \iff 3a + b = -6$.
Odejmujemy równanie (1) od (2): $(3a + b) - (2a + b) = -6 - (-1) \implies a = -5$.
Podstawiamy do (1): $2(-5) + b = -1 \implies -10 + b = -1 \implies b = 9$.
Współczynniki to: $a = -5,\; b = 9$.
Zadanie 13.
Reszta $R(x)$ z dzielenia wielomianu przez wielomian drugiego stopnia $p(x) = (x - 2)(x + 1)$ ma stopień co najwyżej 1, czyli postać liniową $R(x) = ax + b$.
Zapisujemy: $w(x) = Q(x)(x - 2)(x + 1) + ax + b$.
Z treści zadania:
- $w(2) = 5 \implies 2a + b = 5$,
- $w(-1) = -1 \implies -a + b = -1$.
Odejmujemy równania: $2a - (-a) = 5 - (-1) \implies 3a = 6 \implies a = 2$.
Wtedy $b = -1 + a = -1 + 2 = 1$.
Szukana reszta wynosi: $R(x) = 2x + 1$.
Zadanie 14.
Liczba $\frac{1}{3}$ jest pierwiastkiem, więc $w\left(\frac{1}{3}\right) = 0$:
$3 \cdot \left(\frac{1}{3}\right)^3 + m \cdot \left(\frac{1}{3}\right)^2 + 3 \cdot \frac{1}{3} - 2 = 0 \iff 3 \cdot \frac{1}{27} + m \cdot \frac{1}{9} + 1 - 2 = 0$.
$\frac{1}{9} + \frac{m}{9} - 1 = 0 \iff \frac{m+1}{9} = 1 \iff m + 1 = 9 \iff m = 8$.
12: $p(x) = 2x + 1$.
12.A: $a = -5, b = 9$.
13: $R(x) = 2x + 1$.
14: $m = 8$.

🔍 Zobacz pełne rozwiązanie krok po kroku
Zadanie 15. (R)
Dzielenie pisemne $(-3x^4 + 5x^3 + x^2 + 10x + 6) : (x^2 - 2x - 1)$:
1) $-3x^4 : x^2 = -3x^2$. Odejmujemy $-3x^2(x^2 - 2x - 1) = -3x^4 + 6x^3 + 3x^2$. Reszta cząstkowa: $-x^3 - 2x^2 + 10x$.
2) $-x^3 : x^2 = -x$. Odejmujemy $-x(x^2 - 2x - 1) = -x^3 + 2x^2 + x$. Reszta cząstkowa: $-4x^2 + 9x + 6$.
3) $-4x^2 : x^2 = -4$. Odejmujemy $-4(x^2 - 2x - 1) = -4x^2 + 8x + 4$. Reszta ostateczna: $x + 2$.
Iloraz to $-3x^2 - x - 4$, a reszta to $R(x) = x + 2$.
Zadanie 15. A) (R)
Dla $q(x) = x^4 - 8x^3 + 22x^2 - 24x + 9$: suma współczynników $1 - 8 + 22 - 24 + 9 = 0 \implies x = 1$ jest pierwiastkiem.
Dzieląc przez $x - 1$, otrzymujemy $x^3 - 7x^2 + 15x - 9$. Suma współczynników znów wynosi $1 - 7 + 15 - 9 = 0 \implies x = 1$ jest pierwiastkiem podwójnym.
Dzieląc przez $x - 1$, otrzymujemy $x^2 - 6x + 9 = (x - 3)^2$.
Postać iloczynowa: $q(x) = (x - 1)^2 (x - 3)^2$.
Zadanie 15. B) (R)
Postać iloczynowa wielomianu st. 3: $W(x) = a(x + 2)(x - 1)(x - 3)$.
Punkt $(0, 6)$: $W(0) = a(2)(-1)(-3) = 6a = 6 \implies a = 1$.
Wzór: $W(x) = (x + 2)(x - 1)(x - 3) = (x^2 + x - 2)(x - 3) = x^3 - 2x^2 - 5x + 6$.
Zadanie 16. (R)
a) Szukamy pierwiastków wymiernych: $x = -1 \implies 1 + 2 - 3 - 4 + 4 = 0$, $x = 2 \implies 16 - 16 - 12 + 8 + 4 = 0$.
Rozkładamy: $(x + 1)^2 (x - 2)^2 = 0 \implies x \in \{-1, 2\}$.
b) Równanie symetryczne: $2(x^4 - 1) - 5x(x^2 - 1) = 0 \iff (x^2 - 1)[2(x^2 + 1) - 5x] = 0 \iff (x - 1)(x + 1)(2x^2 - 5x + 2) = 0$.
Dla trójmianu: $\Delta = 25 - 16 = 9 \implies x = \frac{5 \pm 3}{4} \in \{\frac{1}{2}, 2\}$.
Rozwiązania: $x \in \{-1, \frac{1}{2}, 1, 2\}$.
Zadanie 16. A) (R)
Wielomian ma pierwiastek $x_0 = 1$. Aby miał dokładnie trzy różne pierwiastki rzeczywiste, trójmian $T(x) = x^2 - mx + m - 1$ musi mieć dwa różne pierwiastki rzeczywiste, z których żaden nie jest równy $1$.
1) $\Delta > 0 \iff (-m)^2 - 4(m - 1) = m^2 - 4m + 4 = (m - 2)^2 > 0 \iff m \ne 2$.
2) $T(1) \ne 0$: $1^2 - m(1) + m - 1 = 1 - m + m - 1 = 0$ dla każdego $m \in \mathbb{R}$!
